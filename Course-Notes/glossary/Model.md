**Model**: assignment of a truth value to every [[propositional symbols|propositional symbol]] (a "posible world").
Example:
- P: It is rainy
- Q: It is a Tuesday
{P = true, Q = false} -> It gaves a value to the propositions (true or false)

The number of possible [[model|models]] is of 2^n, where n is the number of propositions and 2 because each proposition can be evaluated to only 2 states: either true or false.
