**Model checking**: To determine if **[[Knowledge base|KB]]|=*a:
- Enumerate the possible [[model|models]].
- If in every [[model]] where [[Knowledge base|KB]] is true, *a* is true, then [[Knowledge base|KB]] [[Entailment|entails]] *a*.
